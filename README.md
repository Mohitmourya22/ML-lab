# ML Lab

**Machine Learning ke 9 experiments — simple Hindi/Hinglish explanations ke saath.**

ML Lab ek chhota, browser-based learning resource hai. Isme har experiment ke concepts, code snippets ki line-by-line samajh, aur viva ke liye practice questions ek hi page par milte hain. Koi package install ya build step nahi chahiye.

## Experiments

| # | Topic | Kya seekhenge |
|---|---|---|
| 1 | Matplotlib basics | Line plots, styling, NumPy ke saath plotting |
| 2 | Figures, Axes & subplots | Multiple plots, text, grid aur legend |
| 3 | Chart types | Line, histogram, bar aur pie charts |
| 4 | Linear Regression | House-price prediction aur regression metrics |
| 5 | K-Nearest Neighbors (KNN) | Diabetes classification aur evaluation metrics |
| 6 | Naive Bayes | Spam classification, bag-of-words aur TF-IDF |
| 7 | Decision Tree | Wine classification, cross-validation aur tuning |
| 8 | Support Vector Machine (SVM) | Scaling, kernels aur diabetes classification |
| 9 | Artificial Neural Network (ANN) | Scratch se neural network aur Keras model |

## Kaise dekhein

1. Repo ko clone ya download karein.
2. `index.html` ko kisi modern browser mein open karein.
3. Upar diye **Exp 1–9** tabs se experiment chunein.

Ya GitHub par `index.html` khol kar **Go to file** / GitHub Pages jaise static hosting se page dekhein. Is project ko chalane ke liye server, build tool, ya dependency install karna zaroori nahi hai.

## Project mein kya hai?

- Har experiment ka aim aur aasaan bhaasha mein short summary
- Code snippets ke saath unka step-by-step explanation
- Concept samajhne mein madad ke liye viva-style Q&A
- Responsive, single-page interface; light/dark system theme support

## Zaroori note

Yeh project concepts ko samajhne aur viva preparation ke liye hai; yeh ML code runner ya production-ready model package nahi hai. Kuch examples mein external datasets/libraries ka zikr hai, aur page par diye gaye scores dataset, preprocessing aur run ke hisaab se badal sakte hain. Apne assignment ya report mein results use karne se pehle code aur data ko khud verify karein.
